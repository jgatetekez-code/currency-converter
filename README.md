# Currency Converter

A simple currency converter built with HTML, CSS, JavaScript and jQuery.

## Features

- Enter an amount and choose the currencies to convert from and to
- Supports USD, EUR, GBP, JPY and INR
- Shows an error message if the amount is not a valid number
- Clean, colorful design

## Technologies used

- HTML for the page structure
- CSS for the styling
- JavaScript for the logic and calculation
- jQuery for reading the inputs and updating the page

## How to run

1. Download or clone this repository
2. Open the folder in VS Code
3. Right-click `converter.html` and choose "Open with Live Server"

You can also just double-click `converter.html` to open it in your browser. An internet connection is needed because jQuery is loaded from a CDN.

## Files

- `converter.html` - the page structure
- `converter.css` - the styling
- `converter.js` - the conversion logic

## Note

The exchange rates are sample values used for practice. They are fixed and do not update, so the results are not accurate for real money.
